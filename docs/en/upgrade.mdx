# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Security Service.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform Alauda Platform :

|Alauda Container Security Service Version|Supported Alauda Container Platform Version|
|---|---|
|4.8.x|4.2.x|

## Upgrade Path Guidelines

### Patch-Level Upgrade
- **Description**: Upgrades between any patch versions within the same minor version are fully compatible and can be performed directly.
- **Example**: 4.8.0 → 4.8.x
