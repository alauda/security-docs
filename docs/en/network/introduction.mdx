# Introduction

A [Kubernetes network policy](https://kubernetes.io/docs/concepts/services-networking/network-policies/) defines how groups of pods can communicate with each other and with other network endpoints. Because these policies are declared as YAML, it is often difficult to understand the effective topology by reading manifests alone.

Alauda Security Service gathers the network policy information from secured clusters and provides visualization and generation workflows that make these policies easier to understand and operate.

This section focuses on the main network workflows covered in this documentation:

- Network graph
- Network policy generator
- Network baselines
