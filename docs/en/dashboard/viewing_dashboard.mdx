# Viewing Dashboard

## Introduction

The Alauda Security Service Dashboard provides a centralized view of your cluster's security posture. Use it to review security metrics across all resources or narrow the view to selected clusters and namespaces.

## Status Bar

The Status Bar offers a quick overview of key resources in your environment and provides direct navigation to detailed resource lists. The counters reflect your current access scope, as defined by your user roles.

| Counter     | Destination                                                        |
|-------------|--------------------------------------------------------------------|
| Clusters    | Cluster-related views                                              |
| Nodes       | Node inventory and configuration views                             |
| Violations  | Violation views                                                    |
| Deployments | Deployment inventory and configuration views                       |
| Images      | Vulnerability results views                                        |
| Secrets     | Secret inventory and configuration views                           |

*Use the Status Bar to jump quickly from the dashboard to the detailed workflows for clusters, nodes, violations, deployments, images, and secrets.*

A top-level **Resources** filter applies to the dashboard widgets. You can select clusters and namespaces to narrow the data shown. If no selection is made, the view defaults to **All clusters** and **All namespaces**. Changes to the filter are reflected in the dashboard widgets, but not in the Status Bar counters.

Widgets are customizable, allowing you to sort, filter, and adjust their output. Customization options include:

- An **Options** menu for widget-specific settings.
- A **dynamic axis legend** to filter data by hiding or showing axis categories. For example, in the **Policy Violations by Category** widget, you can include or exclude violations by severity.

> **Note:**  
> Widget customization settings are temporary and reset to defaults when you leave the Dashboard.

## Dashboard Widgets

The Dashboard provides several actionable widgets to help you monitor and manage security risks. In the current UI, the main widgets are listed below.

### Policy Violations by Severity

This widget shows the distribution of policy violations by severity for the selected resource scope. Use it to quickly identify whether the current risk is concentrated in `Low`, `Medium`, `High`, or `Critical` findings. When critical violations exist, the widget also highlights the most recent critical items.

### Images at Most Risk

This widget highlights the images with the highest current risk. It lists the top images in the selected scope together with their risk priority and critical or important CVE counts. Use it to prioritize the images that need investigation or remediation first.

> **Note:**  
> When clusters or namespaces are selected in the dashboard filter, the widget reflects only the resources in the filtered scope.

### Deployments at Most Risk

This widget lists the deployments with the highest risk priority in the selected scope. Each row includes the deployment name, resource location, and risk priority so you can move directly into the affected workload.

### Aging Images

This widget helps you find older images that may need refresh, rebuild, or retirement. Use it to assess the age profile of images in the selected scope and prioritize stale images for follow-up.

### Policy Violations by Category

This widget shows the most frequently violated policy categories in the selected scope. Use it to understand whether current issues are concentrated in areas such as `Security Best Practices`, `Privileges`, `Docker CIS`, `DevOps Best Practices`, or `Anomalous Activity`. You can filter by severity through the legend and adjust widget-level display options when available.

---

*By leveraging the Status Bar and Dashboard widgets, you can efficiently monitor, investigate, and improve the security posture of your Kubernetes environment.*
